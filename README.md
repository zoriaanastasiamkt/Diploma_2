# Diploma_2

# Автотесты для API Stellar Burgers

Данный проект содержит пакет автоматизированных тестов, покрывающих ключевой функционал API веб-приложения Stellar Burgers (создание пользователей, авторизация и работа с заказами).

---

## Технологии

| Технология | Версия | Назначение в проекте |
| :--- | :---: | :--- |
| Java | 11 | Язык написания автотестов |
| Apache Maven | 3.9.14 | Сборщик проекта и управление зависимостями |
| JUnit 4 | 4.13.2 | Фреймворк для построения и запуска тест-кейсов |
| REST Assured | 5.3.0 | Отправка HTTP-запросов и валидация API-ответов |
| Allure | 2.21.0 | Построение красивых интерактивных отчетов |
| Project Lombok| 1.18.28 | Автогенерация конструкторов, геттеров и сеттеров |
| JavaFaker | 1.0.2 | Генерация случайных имен, почты и паролей |
| Jackson Databind| 2.15.2 | Сериализация/десериализация POJO-моделей в JSON |
---

## Архитектура проекта

Структура автотестов построена с разделением логики по слоям для упрощения поддержки и масштабируемости кода:

`UserData`, `OrderData` — конфигурационные файлы, содержащие базовые URI, а также эндпоинты (API-пути) для запросов.

`UserModel`, `OrderModel` — POJO-классы (DTO-модели) для сериализации и десериализации JSON-тел запросов с использованием аннотаций Lombok.

`UserSteps`, `OrderSteps` — изолированные шаги (методы отправки запросов), размеченные аннотациями `@Step` для интеграции с Allure.

`UserCreationTest`, `UserLoginTest`, `OrderTest` — тестовые сценарии, содержащие логические блоки проверок

## Настройка и запуск тестов

1) Предварительные требования
Для успешного запуска тестов на локальной машине должны быть установлены:

--- JDK 11

--- Maven (версии 3.8+)

2) Локальный запуск

Чтобы очистить скомпилированные файлы и запустить весь пакет автоматизированных тестов, выполните команду в корневом каталоге проекта:

```bash
mvn clean test
